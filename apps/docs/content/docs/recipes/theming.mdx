---
title: Theming
description: Rebrand the workspace with tokens, a class on one part, and a replaced slot.
---

The component adds a class to the workspace, a class on one part through `classNames`, one replaced slot and the `theme` prop. The stylesheet sets the tokens, with a separate accent for dark mode, both when `data-theme` is set and when the system prefers dark.
