## Create the app and install

Requirements: React 19 (the peer range is `^19.0.0`).

Start from Vite's React and TypeScript template, which includes the types for CSS imports. Vite 7 and 8 are supported. Then add the packages:

```sh
npm create vite@latest my-files -- --template react-ts
cd my-files
npm install @workspacekit/workspace @workspacekit/core
npm install --save-dev @workspacekit/demo-kit
```

`@workspacekit/demo-kit` is only for the sample-files page below. Skip it when you use your own server.

## Render it on sample files

Nothing runs on a server here. `createMemoryAdapter` holds the files in the browser and `sampleFiles` from `@workspacekit/demo-kit` fills it.

```tsx
import { createMemoryAdapter } from '@workspacekit/core/memory';
import { sampleFiles } from '@workspacekit/demo-kit';
import { Workspace } from '@workspacekit/workspace';
import '@workspacekit/workspace/styles.css';

const adapter = createMemoryAdapter({ files: sampleFiles() });

export default function App(): React.JSX.Element {
  return <Workspace adapter={adapter} style={{ height: '100vh' }} />;
}
```

`Workspace` fills its parent. Here the `style` gives it a height; if you leave it out, give the parent one.

## Render it on your server

Swap the adapter for `httpAdapter` and serve a directory with `createFileHandler` from `@workspacekit/server`, as in [Next.js](/docs/getting-started/next). Proxy `/api/files` to that server in Vite's `server.proxy` during development.

```tsx
import { httpAdapter } from '@workspacekit/core/http';
import { Workspace } from '@workspacekit/workspace';
import '@workspacekit/workspace/styles.css';

const adapter = httpAdapter('/api/files');

export default function App(): React.JSX.Element {
  return <Workspace adapter={adapter} style={{ height: '100vh' }} />;
}
```

## Vite configuration

Set `worker: { format: 'es' }` whenever `@workspacekit/spreadsheet` is in the build, as it is with the `@workspacekit/workspace` preset: the spreadsheet worker is code-split, which Vite's default `iife` worker format rejects, so `vite build` fails without it. `@workspacekit/pdf` alone does not need it. The dev server also pre-bundles dependencies, which breaks the worker references in `@workspacekit/pdf` and `@workspacekit/spreadsheet`. Exclude those two and pre-bundle the CommonJS modules the spreadsheet worker imports (Vite's `>` names a dependency of a dependency):

```ts
// not-compiled: needs @vitejs/plugin-react, which comes with the Vite React template and is not installed here
// vite.config.ts
import react from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [react()],
  worker: { format: 'es' },
  optimizeDeps: {
    exclude: ['@workspacekit/pdf', '@workspacekit/spreadsheet'],
    include: [
      '@workspacekit/workspace > @workspacekit/spreadsheet > papaparse',
      '@workspacekit/workspace > @workspacekit/spreadsheet > saxes',
      '@workspacekit/workspace > @workspacekit/spreadsheet > numfmt',
      '@workspacekit/workspace > @workspacekit/spreadsheet > fast-formula-parser',
    ],
  },
});
```

If you install `@workspacekit/spreadsheet` directly rather than through `@workspacekit/workspace`, drop the `@workspacekit/workspace > ` prefix.
