A renderer decides whether it can show a file, how to load its component, and what input it wants. The highest match score wins. Each renderer's component is loaded on demand, so an unused viewer costs nothing.

## Which viewers ship

| Package              | Files                                           | Entry                   |
| -------------------- | ----------------------------------------------- | ----------------------- |
| `@scope/react`       | text, HTML, images, audio, video, TIFF, folders | `lightRenderers`        |
| `@scope/pdf`         | PDF                                             | `pdfRenderer()`         |
| `@scope/docx`        | Word                                            | `docxRenderer()`        |
| `@scope/pptx`        | PowerPoint                                      | `pptxRenderer()`        |
| `@scope/spreadsheet` | XLSX, CSV, TSV                                  | `spreadsheetRenderer()` |
| `@scope/markdown`    | Markdown, with `rendered` and `source` modes    | `markdownRenderer()`    |
| `@scope/code`        | source and config files                         | `codeRenderer()`        |

## Workspace users: allRenderers

With `@scope/workspace`, use `allRenderers()`. It returns every renderer in a fixed order and takes each package's options. Pass the result to `Workspace`.

```tsx
import { httpAdapter } from '@scope/core/http';
import { allRenderers, Workspace } from '@scope/workspace';
import '@scope/workspace/styles.css';

const renderers = allRenderers({ pdf: { workerSrc: '/pdfjs/pdf.worker.min.mjs' } });

export function Files(): React.JSX.Element {
  return <Workspace adapter={httpAdapter('/api/files')} renderers={renderers} />;
}
```

Each package README lists its options, such as the PDF data files and the code editor's `nonce`.

To add your own renderer, put it first: `[logRenderer(), ...allRenderers()]`. The renderer with the highest score wins and a tie goes to the earlier one in the list, so yours wins any tie. A [renderer that scores `specific`](#write-a-renderer) also beats the built-in `generic` and `text` ones whatever its position.

## With @scope/react alone

Without the preset, choose the packages yourself. Put them before `lightRenderers` so they win ties for their own files. Create the array once, at module level.

```tsx
import { httpAdapter } from '@scope/core/http';
import { lightRenderers, Workspace } from '@scope/react';
import { pdfRenderer } from '@scope/pdf';
import '@scope/react/styles.css';
import '@scope/pdf/styles.css';

const adapter = httpAdapter('/api/files');
const renderers = [pdfRenderer(), ...lightRenderers];

export default function Files(): React.JSX.Element {
  return <Workspace adapter={adapter} renderers={renderers} style={{ height: '100vh' }} />;
}
```

## Match scores

`match(file)` returns a number or `false`. `MATCH_SCORE` names the levels, so a renderer says how specific it is instead of picking a number:

| Name        | Score | Use                               |
| ----------- | ----- | --------------------------------- |
| `fallback`  | 1     | Anything, last resort             |
| `text`      | 5     | Plain text                        |
| `generic`   | 10    | A family of files, such as images |
| `specific`  | 20    | A particular extension or name    |
| `directory` | 100   | Folders                           |

Files without an extension, such as `Makefile` and `.env`, match by `basename`.

## Write a renderer

Renderer authors import `defineRenderer` and `MATCH_SCORE` from `@scope/react/renderer-kit`. `input` says what the component is given: `url`, `blob`, `arrayBuffer`, `text` or nothing. `maxBytes` makes a larger file show "too large" with a download instead of being read.

```tsx
import { createMemoryAdapter } from '@scope/core/memory';
import { lightRenderers, Workspace } from '@scope/react';
import { defineRenderer, MATCH_SCORE, type RendererProps } from '@scope/react/renderer-kit';

function Plain({ source }: RendererProps): React.JSX.Element {
  return <pre>{source.kind === 'text' ? source.text : ''}</pre>;
}

const logRenderer = defineRenderer({
  id: 'log',
  match: (file) => file.extension === 'log' && MATCH_SCORE.specific,
  load: async () => ({ default: Plain }),
  input: 'text',
  maxBytes: 1024 * 1024,
});

const adapter = createMemoryAdapter({ files: { 'run.log': 'started' } });
const renderers = [logRenderer, ...lightRenderers];

export function Logs(): React.JSX.Element {
  return <Workspace adapter={adapter} renderers={renderers} />;
}
```
