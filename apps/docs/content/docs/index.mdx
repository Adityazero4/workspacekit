The workspace has two halves. A route handler on your server exposes a directory, and one React component in the browser shows it. Both are short.

- New here: start with [Next.js](/docs/getting-started/next) or [Vite](/docs/getting-started/vite).
- Connect your own storage: [the adapter](/docs/concepts/adapter) and the [S3](/docs/recipes/s3) and [custom adapter](/docs/recipes/custom-adapter) recipes.
- Lock it down: [authorize and policy](/docs/concepts/policy) and [security](/docs/server/security).
- Make it yours: [styling](/docs/styling) and [renderers](/docs/concepts/renderers).
- Using a coding agent: [coding agents](/docs/coding-agents).

Every example in these pages that renders UI is live, running on the in-memory adapter. The [home page](/) runs the whole workspace with a simulated agent.
