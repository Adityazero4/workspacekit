# Changelog

All notable changes are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the packages will follow [Semantic Versioning](https://semver.org/) once they are published.

## Unreleased

### Added

- The core package: the adapter contract, the tree store, uploads, and the HTTP and in-memory adapters.
- `@workspacekit/server`: a Fetch-API request handler with a required per-request `authorize` callback.
- `@workspacekit/react`: the `Workspace` component, the file tree, search, tabs, upload and the light renderers.
- Renderer packages for PDF, Word, PowerPoint, spreadsheets, Markdown and code, and the `@workspacekit/workspace` preset.
- `@workspacekit/demo-kit`, `@workspacekit/create-workspace`, the examples, and per-package `README.md`, `AGENTS.md` and `llms.txt`.
- The Apache-2.0 `LICENSE`, `NOTICE`, `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md`.
